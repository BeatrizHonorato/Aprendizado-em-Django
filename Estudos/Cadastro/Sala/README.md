# 📚 Sistema de Cadastro de Professores (CRUD)

Este projeto é um sistema simples de **cadastro de professores**, desenvolvido com **Django**, com foco em aprendizado de CRUD (Create, Read e Delete).

## 🚀 Funcionalidades

- ✅ Cadastro de professores
- 📋 Listagem de professores cadastrados
- 🗑️ Exclusão de professores
- 🔐 Proteção CSRF nas operações sensíveis
- 🧱 Estrutura organizada seguindo boas práticas do Django

## 🛠️ Tecnologias Utilizadas

- Python 3.11
- Django 5.x
- HTML5
- Bootstrap 5
- SQLite (banco padrão do Django)

## 📂 Estrutura do Projeto

- **Models** para representar o Professor
- **Views** para criação, listagem e exclusão
- **Templates HTML** para interface do usuário
- **URLs nomeadas** para melhor organização e manutenção
